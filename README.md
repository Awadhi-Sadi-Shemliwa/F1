# F1: Formula 1 data science projects

Each project lives in its own folder with its notebook, notes, interactive walkthrough and video.

| Project | What it covers |
|---|---|
| [The Price of a Place: grid position and points](grid-position-points/) | How starting-grid position relates to a points finish (2014–2025), and whether a grid penalty costs every car the same. |
| [F1 Lap-Time Lab: Linear Regression vs Random Forest](lap-time-lr-vs-rf/) | Predicting lap times from fuel, tyre age and traffic on 862 laps of the 2023 Italian GP, with an interactive Power BI dashboard and walkthrough video. |
